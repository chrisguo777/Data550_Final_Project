# F75 Project

This repository is the reproducible project skeleton for the DATA 550 team analysis
of the `f75_interim.csv` dataset. The repository is intentionally organized into
separate data, code, output, and report components so the final report can be rebuilt
from scripts instead of keeping all logic inside a single `.Rmd` file.

## Repository contents

- `data/`
  - `f75_interim.csv`: raw study dataset
  - `cleaned_data.rds`: cleaned analysis dataset generated by the pipeline
- `code/`
  - `00_data_cleaning.R`: imports and prepares the analysis dataset
  - `01_boxplots.R`: boxplot module for MUAC, weight, and height
  - `02_kaplan_meier_curve.R`: survival analysis module
  - `03_summary_tables.R`: summary table module, including Table 1 and Table 2
  - `04_regression.R`: regression modeling module
  - `05_other_misc_code.R`: correlation heatmap and scatterplot module
- `output/figure/`
  - generated figures used in the report
- `output/table/`
  - generated tables and saved analysis objects used in the report
- `report/`
  - `final_report.Rmd`: source for the final report
  - `final_report.html`: rendered final report
- `Makefile`
  - reproducible workflow for building the report

## How to generate the final report
run:

```sh
make
```

This build will:

- clean and save the analysis dataset
- generate the required figure
- generate the required tables
- render the final report to `report/final_report.html`

## What the report contains

The final report is set up to include:

- a short project overview and workflow description
- a data section describing the cleaned analysis dataset
- the required figure section
- the required table section
- the Kaplan-Meier, regression, and supplementary EDA sections


## Where the required figure code is

The required figure code lives in `code/01_boxplots.R`.
required figure output: `output/figure/xxx_figure.png`


## Where the required table code is

The required table code lives in `code/03_summary_tables.R`.
required table output: `output/table`
